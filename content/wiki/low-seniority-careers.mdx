# อาชีพที่ไม่พึ่งระบบอาวุโส

โน้ตแนวทางอาชีพที่เราโอเค: งานที่ไม่มีการกดขี่ด้วยระบบรุ่นพี่รุ่นน้องแบบที่เจอในวงการแพทย์ ตัดสินคนจากผลงานมากกว่าอายุงาน และย้ายออกได้ถ้าเจอที่ไม่ดี

หลักคิด: **ความสามารถ > อายุงาน > ตำแหน่ง > สถาบันที่จบ**

## ทำไมบางอาชีพอาวุโสเข้มข้น

ข้อสังเกตที่ว่า "คนมาจากที่เดียวกัน อยู่ที่เดียวกันนาน ๆ" มีส่วนจริง แต่มักเกิดจากหลายปัจจัยรวมกัน

- **Closed profession**: เข้าอาชีพได้ผ่านใบอนุญาต การฝึกเฉพาะทาง หรือเครือข่ายวิชาชีพเท่านั้น
- **Rigid hierarchy**: ลำดับชั้นชัด เช่น อาจารย์แพทย์ แพทย์ประจำบ้าน นักศึกษาแพทย์
- **Power dependency**: รุ่นน้องต้องพึ่งรุ่นพี่ในการประเมิน รับรอง และความก้าวหน้า
- **Low mobility**: ย้ายทีม ย้ายองค์กร หรือเปลี่ยนสายยาก เลยต้องทนสภาพเดิม
- **Institutional culture**: ธรรมเนียมส่งต่อรุ่นสู่รุ่น "เคยโดนมาแบบไหนก็ทำต่อแบบนั้น"

มีลำดับชั้นไม่ได้แปลว่าต้องกดขี่ งานแพทย์ต้องมีผู้กำกับเพื่อความปลอดภัยของผู้ป่วย แต่การดูหมิ่นหรือกลั่นแกล้งไม่ใช่สิ่งจำเป็น งานวิจัยเรื่องการกลั่นแกล้งในวงการแพทย์และสุขภาพชี้ว่าลำดับชั้น การพึ่งพาผู้มีอำนาจ และการมองว่าพฤติกรรมแบบนี้ปกติ เป็นปัจจัยหลัก

แยกให้ออกว่ากำลังหนีอะไร เพราะแต่ละอย่างต่างกัน

- **Seniority**: ต้องเคารพคนมาก่อน ถูกใช้งานหรือดุโดยไม่มีเหตุผล ความก้าวหน้าผูกกับอายุงาน
- **Hierarchy**: หัวหน้าสั่งอะไรต้องทำ แม้เห็นว่าผิด
- **พรรคพวก / วงการปิด**: คนจบที่เดียวกันช่วยกัน คนนอกเข้ายาก

บางอาชีพไม่มีรุ่นพี่รุ่นน้อง แต่ยังมีพรรคพวกหรืออำนาจหัวหน้าสูง และงานที่ไม่มีหัวหน้าก็ยังมีแรงกดดัน แค่อำนาจย้ายไปอยู่ที่ลูกค้า นักลงทุน หรือแพลตฟอร์มแทน

## เกณฑ์เลือกงาน

- **Meritocracy**: ผลงานและความสามารถสำคัญกว่าอายุงาน
- **Portability**: ทักษะพกไปใช้บริษัทหรือประเทศอื่นได้
- **Autonomy**: มีสิทธิตัดสินใจว่าจะทำงานอย่างไร
- **Exit options**: ลาออก เปลี่ยนทีม หรือหาลูกค้าใหม่ได้โดยอาชีพไม่สะดุด ข้อนี้สำคัญที่สุด เพราะถ้าออกได้ง่าย อำนาจของหัวหน้าที่ไม่ดีก็จำกัดลงเอง

ถ้าจะเป็นพนักงานประจำ ให้มองหา product-based company, มี IC track (Staff / Principal โดยไม่ต้องเป็นผู้จัดการ), วัดผลจาก outcome, จ้างแบบ global และมีเกณฑ์เลื่อนตำแหน่งโปร่งใส บริษัทที่บอกว่า "flat" ก็ยังมีลำดับชั้นซ่อนอยู่ ต้องดูวัฒนธรรมจริง ไม่ใช่แค่คำโฆษณา

## ลำดับสำหรับเรา

จากพื้นฐาน Software Engineering และการสร้างธุรกิจของตัวเอง

1. **Indie SaaS Founder**: มีผลิตภัณฑ์และลูกค้าของตัวเอง ไม่ต้องรอใครอนุมัติ แต่รับความเสี่ยงธุรกิจเอง
2. **Independent Technical Consultant**: ขายความเชี่ยวชาญ Software Architecture, Cloud, AI ให้หลายลูกค้า เลือกงานได้
3. **Global Remote IC Engineer**: รายได้ประจำ ในบริษัทที่ให้ผู้เชี่ยวชาญโตได้โดยไม่ต้องเข้าสายบริหาร

สรุป: งานที่เป็นเจ้าของผลงานและเข้าถึงลูกค้าตรง ๆ ตอบโจทย์ที่สุด ถ้าอยากได้ความมั่นคงด้วย สายผู้เชี่ยวชาญในบริษัทที่ประเมินโปร่งใสคือทางสมดุล

เคารพความเชี่ยวชาญของคนมีประสบการณ์ ไม่เท่ากับยอมรับอำนาจจากความอาวุโส เรียนจากคนเก่งกว่าได้ โดยไม่ต้องอยู่ในวัฒนธรรมที่ห้ามถาม

## อันดับที่พึ่งอาวุโสต่ำที่สุด

สมมติว่าทำงานเอง มีลูกค้าหรือผู้ซื้อหลายราย และไม่ขึ้นกับผู้รับรองหรือองค์กรเดียว ทั้งหมดนี้ "ต่ำมาก"

- Indie SaaS Founder, Micro-SaaS, Digital Product Creator, Productized Service Owner
- Independent Software Developer / Architect / Technical Consultant
- Freelance Data / AI Consultant, Independent Quant Developer
- Bug Bounty Hunter, Independent Security Researcher
- Online Course Creator, Independent Technical Trainer
- Independent Writer / Publisher, Content Creator
- Independent Graphic / UI Designer, 3D Asset Creator
- Open-source Tool Creator ที่ขายบริการเอง
- E-commerce Owner, ธุรกิจซ่อมอุปกรณ์ของตัวเอง
- Trading ด้วยทุนตัวเอง (เสี่ยงขาดทุนสูง)

อิสระมีต้นทุน: OECD (2025) พบว่าผู้ประกอบอาชีพอิสระได้อำนาจจัดการงานมากกว่า แต่เสี่ยงเรื่องความมั่นคงของรายได้

## สายที่ควรระวัง

ไม่ได้แปลว่าไม่ดีหรือทุกที่กดขี่ แต่โครงสร้างพึ่งผู้มีอำนาจและลำดับชั้นสูง โดยเฉพาะช่วงฝึก

- **แพทย์ / ศัลยแพทย์ระหว่างฝึก**: อาจารย์แพทย์ ระบบประเมิน การรับรองทักษะ
- **ทหาร / ตำรวจ**: ยศและสายบังคับบัญชา
- **ข้าราชการบางหน่วย**: ขั้นตำแหน่งและระบบราชการ
- **อัยการ / ผู้พิพากษา**: ระบบวิชาชีพและลำดับตำแหน่ง
- **นักวิชาการในมหาวิทยาลัย / นักวิจัยบัณฑิตศึกษา**: หัวหน้าแล็บ อาจารย์ที่ปรึกษา ทุน การประเมิน
- **นักบิน / ลูกเรือ**: ลำดับบังคับบัญชาและกฎความปลอดภัย
- **สำนักงานกฎหมายใหญ่**: Partner / Associate
- **Corporate management บางแบบ**: ผู้บริหารหลายชั้น
